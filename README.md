# fsaudm.github.io

Personal site for Farid Saud.

## Pages

- `/` - landing page (gesture mode / traditional)
- `/handcv/` - [HandCV](https://github.com/fsaudm/HandCV) gesture-controlled resume
- `/resume/` - traditional resume

## Stack

- **Landing**: standalone HTML/CSS
- **HandCV**: vanilla JS + Canvas + MediaPipe (synced from [fsaudm/HandCV](https://github.com/fsaudm/HandCV))
- **Resume**: Jekyll + custom Onyx-inspired theme with [Lukas Sans](https://shawnlukas.com/)

## Local dev

```bash
bundle install
bundle exec jekyll serve --port 4000
```
